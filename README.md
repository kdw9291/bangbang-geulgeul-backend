# backend — Java 서버

아직 시작하지 않았다. `PROJECT_WORKFLOW.md`의 **S3 서버 연동** 단계에서 만든다.

## 확정된 것

- 언어는 **Java**. 앱 프레임워크(Flutter) 선택과 독립적이다.
- 저장할 데이터는 **긁은 지역 코드 배열**이다. 마스크 픽셀을 저장하지 않으므로
  API가 단순해진다.
- 지역 코드는 통계청 시군구 코드 5자리(`sgg`)를 그대로 쓴다.
  예: `11110` 서울 종로구.

- 저장소를 이 디렉토리에 둘지 별도 저장소로 분리할지
